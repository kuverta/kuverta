Your email and your paper post, in one list, sorted — and it says why.

kuverta is a keyboard-first desktop mail client for macOS, Linux and Windows. It keeps your mail on your computer, reads scanned letters from Paperless-ngx beside it, and runs its models locally unless you choose otherwise.

What makes it different

Mail and paper post in one place

A postal address is set up like an account, with Paperless-ngx as its server. Letters read like mail — the sender, the subject, the text — and are sorted by the same rules. A small Raspberry Pi scanner can photograph them as they are put down.

Paper post →

Sorting that explains itself

Every message is filed as personal, newsletter, marketing, transactional, notification or unknown, from headers you can check. "Unknown" is a real answer, not a guess. File a sender once and the next one follows.

Reading and sorting →

Cleanup and Unsubscribe

The header counts the newsletters, marketing and notifications still in your Inbox. Cleanup deals with a whole kind of mail at once, and lists every sender you can unsubscribe from — one click, by mail, or on their page.

Cleanup →

Models on your computer first

Reading scanned letters and sorting mail can use models run by Ollama on this computer. A hosted service is your choice, per job, and the settings say plainly what it would send.

Models →

Keyboard-first, never keyboard-only

j k to move, e to archive, z to undo — and a button for everything that matters, so a reply never depends on knowing that R is reply.

Keyboard shortcuts →

Careful with your mail

Delete means move to Trash, and every change waits in an undo window before it reaches the server. Messages are shown as text, so nothing in them is loaded from the internet. OpenPGP signing and encryption are built in — no GnuPG needed.

A closer look

Try it

Installers for macOS 11 or later (Apple Silicon and Intel), Linux (AppImage, .deb, .rpm) and Windows 10 or later. A setup assistant opens on the first run and can bring your accounts over from Thunderbird and Apple Mail.

For developers

kuverta is Rust and Tauri, with a JavaScript triage surface that runs both inside the app and as a Thunderbird extension. A Docker stack gives you an IMAP server, an SMTP sink and a Paperless-ngx to develop against, so none of it needs your real mailbox.

  • Build from source and run the tests
  • The kuverta command line
  • An MCP server that lets an assistant read and file mail, and never send it
  • scannerd, the Raspberry Pi letter scanner
  • Architecture and the design decisions behind it
git clone https://github.com/kuverta/kuverta
cd kuverta
make dev-up     # Dovecot, an SMTP sink, Paperless-ngx
make e2e        # register the dev account and sync it
make triage     # open the window on the scratch store
